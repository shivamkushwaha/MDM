Live Graph Optimization Studio

Move vertices, adjust edge parameters, and see shortest paths, maximum flow and minimum spanning trees update immediately.

Paste network data (CSV)

Paste one row per directed connection. Use the headers from, to, weight, capacity, lower, upper. The weight column is used for shortest path and MST. For flow, upper is the maximum capacity when supplied; otherwise capacity is used. Blank weight defaults to 1 and blank lower bound defaults to 0.
Loading CSV replaces the current connections. Your selected origin/source and destination/sink are retained, even when an endpoint is not listed in the pasted data.

Algorithm settings

Dijkstra uses the edge cost/length. Edge costs must be non-negative.
Directed edges are used. Lower bounds are enforced using a feasible-circulation transformation.
Kruskal treats each connection as undirected and uses its cost as the edge weight.

Selected edge

Select an edge in the graph or edge list to edit it.
When enabled, moving either endpoint changes this edge's cost automatically.
Flow on this edge must be between its lower and upper capacity. Lower capacity cannot exceed maximum capacity.

Connections

Select an edge to edit. Costs and capacities are independent.

How to interact

  1. Drag a node; linked geometric costs update.
  2. Select an edge and adjust its sliders.
  3. Switch algorithm tabs; the result is recomputed.
  4. Use Connect nodes, then click two vertices to add an edge.
  5. Use Add node to expand the network.
  6. Click a vertex to select it, then use Delete selected node. All connections attached to that vertex are removed too.
