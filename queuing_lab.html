Theoretical operating characteristics

The calculations below use the current λ, μ and c settings. Steady-state values are shown only when the model is stable.

Key formulas

M/M/1 stability: λ < μ
M/M/c stability: λ < cμ
ρ = λ / (cμ) · utilisation per server
L = Lq + λ/μ
W = Wq + 1/μ (W and Wq are in minutes)
L = λW and Lq = λWq (Little's Law)

For M/M/1, c = 1 and ρ = λ/μ. For M/M/c, the Erlang-C formula is used.

Student experiment laboratory

Choose an experiment to load its parameters into the simulation. Press Start to observe the system and then discuss the questions.

1. Effect of arrival rate

Set μ = 0.1667 customers/minute and c = 1. Increase λ from 0.0333 towards 0.1500 customers/minute. Observe queue length and waiting time.

2. High server utilisation

Set λ = 0.1333 and μ = 0.1667 customers/minute, with c = 1. Increase λ gradually and observe waiting time as utilisation approaches 100%.

3. Unstable single-server system

Set λ = 0.1333 and μ = 0.0833 customers/minute, with c = 1. Observe queue growth and why a steady-state distribution does not exist.

4. Economies of multiple servers

Set λ = 0.1333 and μ = 0.0833 customers/minute. Compare c = 1, 2 and 3. One server is unstable while two and three servers are stable.

5. Transient versus steady state

Start from an empty system with stable parameters. Compare finite-run averages with theoretical long-run values. Repeat with a longer run.

6. Demand shock

Start with a stable system. Pause, change λ (customers/minute), and restart to compare the response under different demand levels.

Questions for students

  1. What happens to Wq as utilisation approaches 100%?
  2. Why is λ < cμ necessary for a stable M/M/c system?
  3. Why can adding a server reduce waiting cost but increase service cost?
  4. Why might a short simulation differ from theoretical steady-state values?
  5. Which server configuration minimises total cost for the cost assumptions provided?
